Private vital documents — driver's licenses, Social Security cards, birth certificates, marriage licenses, green cards, and court filings for Omar's own household — are cataloged the same rigorous way, but deliberately kept off this page and off GitHub entirely. They contain live SSNs, license numbers, and USCIS numbers. That catalog lives in records/private-vital-documents/ on the family's own servers (Mac, ai5080, ai3070), gitignored, never public. The facts extracted from them — names, dates, relationships — are the same facts that appear in the tree and book above.
